# Field visits contract

Representatives may create only their own current or legitimately offline-captured visit, for a segment allowed by `field_ret` or `field_dist`, with same-day attendance. The server validates location ranges, accuracy, capture timestamps, outcome, deterministic private evidence path, and ownership.

Admin reporting supports India date range, representative, segment, outcome, search, pagination, and complete filtered totals. Evidence paths are metadata; short-lived signed URLs are generated on demand and are never persisted.
