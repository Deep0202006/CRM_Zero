# Route and Component Plan

## Routes
- `/visits`: My Visits (Field Staff)
- `/visits/new`: Log a new visit
- `/admin/visits`: All Visits (Admin)

## Components
- `VisitForm.tsx`: Form for logging outcome and notes
- `VisitList.tsx`: List of past visits
- `CheckInGate.tsx`: Ensures the user clocks in and takes a selfie before visiting.
