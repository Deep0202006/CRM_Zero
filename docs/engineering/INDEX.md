# CRM Engineering Intelligence

This directory is the compact engineering knowledge layer. Current product
code, schema, tests, `docs/contracts/**`, and GitHub CI remain authoritative
implementation evidence.

Default task context is `AGENTS.md`, one Graphify query (600–1000 tokens), one
domain entry, up to two directly relevant contracts, referenced authority and
capability entries, and at most eight matching lessons. Cross-domain work may
expand only when evidence requires it. Prefer query → targeted read → modify;
never load this entire registry, historical plans, Git history, or graph cache
by default.
