| 2026-08-10 | Calls | Free-text clients stayed local and new calls waited behind old queue failures. | UI client references, offline repair, and server validation did not share one semantic contract; the outbox lacked exact-item priority confirmation. | UI client-reference semantics, offline payload semantics and server validation must share one canonical contract. Custom user-entered identities must never be silently interpreted as relational UUID identifiers. | 2026-08-10 | Owner production safety | Production testing could be interpreted as permission to create and later delete dummy business records. | The harness prohibited fabricated records generally but did not state that cleanup does not make a live production test write safe. | Automated tests, QA fixtures, and smoke tests must never create dummy/test business data in live production Supabase. Production verification is read-only unless the owner explicitly authorizes the exact mutation. Use mocks, isolated fixtures, local/preview environments, and read-only reconciliation; never insert dummy data and then delete it. | Golden Principles, production-safety skill, release guidance, invariant guard, and harness self-test. | Permanent owner constraint |
